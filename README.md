# AI 宠物管家

AI 宠物管家是一款面向中文用户的跨端宠物生活管理产品。项目将首先以微信小程序验证核心体验，帮助宠物主人集中维护宠物档案、健康事项与日常照护计划，并在后续阶段引入可靠、可追溯的 AI 辅助能力。

> 当前仓库仅进行项目初始化与产品文档整理，尚未创建页面、接入数据库或实现登录。

## 产品定位

- **目标用户**：需要管理一只或多只宠物日常照护事务的中文宠物主人。
- **核心价值**：将分散的宠物信息、健康记录、提醒和知识咨询汇总到一个易用的个人管家中。
- **产品边界**：AI 提供信息整理、提醒建议和一般性知识辅助，不替代执业兽医的诊断与治疗。
- **首发平台**：微信小程序。
- **未来平台**：iOS App、Android App，并尽可能复用领域模型、业务逻辑和跨端 UI 能力。

详细需求见 [`docs/product-requirements.md`](docs/product-requirements.md)。

## 技术路线

项目计划采用以下技术栈：

- **应用框架**：Taro
- **视图层**：React
- **开发语言**：TypeScript（启用严格类型检查）
- **首期构建目标**：微信小程序
- **后续构建目标**：iOS、Android

架构上将遵循“领域逻辑与平台能力分离”的原则：

1. 以平台无关的领域模型承载宠物、健康记录、提醒等核心概念。
2. 通过接口适配微信、iOS 和 Android 的登录、通知、文件等平台能力。
3. 将页面、可复用组件、状态管理、服务访问和类型定义分层组织。
4. 对 AI、存储和后端服务保留抽象边界，避免早期绑定具体供应商。

本阶段不安装前端依赖，也不提前生成业务页面，以便在技术设计确认后选择与目标平台匹配的稳定版本。

## 开发阶段

1. **阶段 0：产品与技术设计**（当前）——明确需求范围、信息架构、交互原型、技术方案和质量基线。
2. **阶段 1：工程骨架与基础体验**——初始化 Taro + React + TypeScript，建立跨端分层、设计系统、测试与持续集成。
3. **阶段 2：本地核心闭环**——实现宠物档案、健康记录和提醒的最小可用闭环，暂不依赖账号体系。
4. **阶段 3：云端与微信能力**——在隐私与安全方案评审通过后，接入登录、云端同步、消息通知和服务端能力。
5. **阶段 4：AI 能力**——在安全边界、内容治理和效果评估完备后，上线 AI 宠物助手。
6. **阶段 5：原生应用扩展**——适配并发布 iOS、Android，完善多端同步和平台特性。

阶段目标、交付物和验收条件见 [`docs/development-plan.md`](docs/development-plan.md)。
